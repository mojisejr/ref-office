# ขอบเขตงาน กติกา Fastwork และสัญญาเรื่องข้อมูล

## ทำ

- จัดรูปแบบรายการอ้างอิง APA 7 ภาษาไทยและอังกฤษ ตามคู่มือของสถาบันถ้ามี
- ตรวจข้อมูลของแต่ละรายการกับแหล่งจริง (DOI/Crossref)
- ตรวจว่าอ้างอิงในเนื้อหาตรงกับบรรณานุกรม (แพ็กเกจทั้งบทและด่วน)
- รายงานการแก้: แก้อะไร เพราะอะไร และรายการไหนต้องการข้อมูลเพิ่มจากลูกค้า

## ไม่ทำ (ใช้ข้อความ 6 ใน replies)

- เขียนหรือเรียบเรียงเนื้อหา, paraphrase เพื่อหลบตัวตรวจ plagiarism หรือตัวตรวจ AI
- หาแหล่งอ้างอิงใหม่ให้ หรือเพิ่มรายการที่ลูกค้าไม่ได้ให้มา
- เติมข้อมูลที่ยืนยันกับแหล่งจริงไม่ได้ ให้ใส่ ม.ป.ป. หรือแจ้งในรายงานแทน
- รูปแบบอื่นนอกจาก APA (ตอนนี้)
- แปลรายการเป็นภาษาอังกฤษ + [in Thai] สำหรับวารสาร TCI (ตอนนี้)

## กติกา Fastwork (ข้อตกลงฟรีแลนซ์ เวอร์ชัน 7)

- ติดต่อ ถามข้อมูล และส่งงานได้เฉพาะในแชทของ Fastwork
- ห้ามแลกช่องทางติดต่อ ห้ามรับเงินหรือส่งงานที่อื่น ห้ามแบ่งจ่ายนอกระบบ
  ถ้าฝ่าฝืน Fastwork มีสิทธิระงับหรือยกเลิกบัญชี และเรียกค่าเสียหายได้
- Fastwork เข้าไปอ่านแชทได้เพื่อตรวจเรื่องนี้
- ค่าคอมมิชชั่นแบบเพดานสะสม: เมื่อยอดสะสมของคู่ฟรีแลนซ์กับลูกค้าถึงเกณฑ์ ออเดอร์ถัดไปของคู่นั้นเหลือ 0%
  ลูกค้าที่กลับมาส่งงานบทต่อไปจึงคุ้มกับเรา

## สัญญาเรื่องข้อมูล (PDPA)

- ไฟล์ลูกค้าใช้เพื่องานนั้นเท่านั้น เก็บเฉพาะใน `jobs/` ซึ่ง git ไม่ track
- ลบหลังส่งงาน 30 วัน (`bun run jobs` บอกว่างานไหนครบกำหนด)
- มี AI ช่วยอ่านรายการอ้างอิง ระบุไว้ในหน้าบริการแล้ว
  setting ที่ให้นำบทสนทนาไปใช้ปรับปรุงโมเดลในบัญชี Claude ของเจ้าของปิดอยู่
- repo นี้เป็น public ห้ามมีชื่อลูกค้า เนื้อหาไฟล์ หรือรายการอ้างอิงของลูกค้า ใน commit, PR, issue หรือ event
