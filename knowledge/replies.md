# ข้อความสำเร็จรูป (วางใน Fastwork)

ส่วนที่อยู่ใน `< >` agent จะเติมให้ทุกครั้ง ข้อความทุกอันห้ามมีลิงก์หรือช่องทางติดต่ออื่น

## 1. ทักครั้งแรก

```
สวัสดีครับ ขอข้อมูล 9 ข้อเพื่อประเมินราคาให้ครับ
1. สถาบันหรือวารสารไหน มีคู่มือการเขียนอ้างอิงไหม (แนบมาได้เลย)
2. APA เวอร์ชันไหน (6 หรือ 7)
3. ต้องการแก้รูปแบบอย่างเดียว หรือตรวจให้ตรงกับเนื้อหาด้วย
4. มีประมาณกี่รายการ
5. ส่งทั้งเล่ม/ทั้งบท หรือเฉพาะบรรณานุกรม
6. ไฟล์ใช้ EndNote, Zotero หรือ iThesis ไหม
7. มีรายการภาษาไทยไหม เรียงไทยก่อนอังกฤษหรือแยกส่วน
8. ต้องการรับงานวันไหน กี่โมง
9. อาจารย์คอมเมนต์อะไรมาไหม (ถ้ามี แนบมาด้วยครับ)

ไฟล์ของคุณใช้เพื่อทำงานนี้เท่านั้น และลบหลังส่งงาน 30 วันครับ
```

## 2. เสนอราคา

```
ประเมินแล้ว <N> รายการครับ
แพ็กเกจ: <ชื่อแพ็กเกจ> ราคา <ราคา> บาท
ส่งงานภายใน: <วัน เวลา> นับจากชำระเงิน
ได้รับ: ไฟล์ Word + PDF + รายงานการแก้<, และตรวจอ้างอิงในเนื้อหาให้ตรงกับบรรณานุกรม>
ออกใบเสนอราคาให้แล้วครับ
```

## 3. รับงานแล้ว

```
ได้รับการชำระเงินแล้วครับ เริ่มงานทันที จะส่งภายใน <วัน เวลา> ครับ
```

## 4. ส่งงาน

```
ส่งงานแล้วครับ มีไฟล์ Word, PDF และรายงานการแก้
สรุป: จัดรูปแบบ <N> รายการ, แก้ไข <X> รายการ<, ตรวจกับเนื้อหาพบ <Y> จุดที่ไม่ตรงกัน>
<รายการที่ต้องการข้อมูลเพิ่มจากคุณ <Z> รายการ (ดูในรายงานหัวข้อ "รอข้อมูล")>
ถ้าต้องการแก้ แจ้งได้อีก <3> ครั้งครับ
```

## 5. ขอให้แปลงไฟล์ EndNote / Zotero

```
ไฟล์นี้มีโค้ดของ <EndNote/Zotero> อยู่ ถ้าแก้ตรงๆ โปรแกรมจะเขียนทับกลับครับ
รบกวนแปลงเป็นข้อความธรรมดาก่อน (EndNote: Convert to Plain Text / Zotero: Unlink Citations)
แล้วส่งไฟล์ที่แปลงแล้วมาใหม่นะครับ
```

## 6. ปฏิเสธงานนอกขอบเขต

```
ขออภัยครับ ร้านรับเฉพาะงานจัดรูปแบบและตรวจความถูกต้องของรายการอ้างอิง
ไม่รับเขียนเนื้อหา และไม่หาหรือเพิ่มแหล่งอ้างอิงใหม่ให้ครับ
ถ้ามีรายการอ้างอิงอยู่แล้ว ยินดีจัดให้ถูกต้องครับ
```

## 7. คำขอแก้ที่เป็นงานใหม่

```
คำขอนี้เป็น<การเพิ่มรายการใหม่ <N> รายการ / งานนอกขอบเขตเดิม> ครับ
ส่วนนี้คิดเป็นงานเพิ่ม <ราคา> บาท ส่งภายใน <เวลา> ถ้าตกลงจะออกใบเสนอราคาให้ครับ
```
