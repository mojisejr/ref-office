# 00 · เจ้าของ 3 นาที: งานเข้าแล้วทำอะไร

คุณคุยกับลูกค้าใน Fastwork ส่วน agent ทำงานในออฟฟิศนี้ ทุกอย่างที่ลูกค้าเห็นอยู่ใน Fastwork เท่านั้น

## เปิดออฟฟิศ

เปิดโฟลเดอร์ `checkouts/ref-office` ในหน้าต่าง VS Code แยกจากงานโค้ด แล้วเริ่ม Claude
ถ้าจะรับงานลูกค้า พิมพ์ `/model sonnet` ก่อน (ดูเหตุผลใน [02-model-choice](02-model-choice.md))
agent จะขึ้นรายการงานค้างเรียงตามเดดไลน์ให้เองทุกครั้ง

## งานหนึ่งชิ้น

| # | ที่ไหน | คุณทำ | agent ทำ |
|---|---|---|---|
| 1 | Fastwork | ลูกค้าทักมา → วางข้อความ "ทักครั้งแรก" จาก [replies](../knowledge/replies.md) | — |
| 2 | ออฟฟิศ | ลูกค้าตอบและส่งไฟล์มา → ดาวน์โหลดไฟล์ แล้วพิมพ์ `งานใหม่` + ลากไฟล์ลงแชท + คัดลอกคำตอบลูกค้ามาวาง | นับรายการ เสนอแพ็กเกจ ราคา และเวลาส่ง พร้อมข้อความใบเสนอราคา |
| 3 | Fastwork | ส่งใบเสนอราคาตามที่ agent บอก → ลูกค้าจ่ายเงิน | — |
| 4 | ออฟฟิศ | พิมพ์ `จ่ายแล้ว` | เริ่มงาน และร่างข้อความ "รับงานแล้ว" ให้คุณวางใน Fastwork |
| 5 | ออฟฟิศ | ถ้า agent ถาม ให้ตอบรายการที่เด้ง (มักใช้เวลา ≤5 นาที) | ทำงานจนผ่านตัวตรวจ |
| 6 | ออฟฟิศ → Fastwork | agent บอก `พร้อมส่ง` → อัปโหลดไฟล์จากโฟลเดอร์ที่บอก + วางข้อความส่งงาน | บอกที่อยู่ไฟล์และร่างข้อความส่งงาน |
| 7 | ออฟฟิศ | พิมพ์ `ส่งแล้ว` | บันทึกเวลาส่ง และนับ 30 วันก่อนลบไฟล์ |

**ลูกค้าขอแก้:** คัดลอกข้อความลูกค้ามาวาง แล้วพิมพ์ `แก้งาน <รหัสงาน>` agent จะบอกว่าเป็นการแก้ (ฟรี เหลืออีกกี่ครั้ง) หรือเป็นงานใหม่

## สามข้อที่ห้ามลืม

1. **ห้ามส่งลิงก์ เบอร์ LINE หรืออีเมลให้ลูกค้า** ข้อตกลงของ Fastwork ห้ามไว้ และอาจถูกระงับบัญชี
2. **อ้างถึงลูกค้าด้วยชื่อเล่นหรือรหัสงาน** ไม่ต้องใช้ชื่อจริงในออฟฟิศ
3. **งานที่เกินขอบเขต** (เขียนเนื้อหา หาอ้างอิงเพิ่ม) ใช้ข้อความ "ปฏิเสธ" ใน replies ได้เลย ไม่ต้องคิดคำเอง
