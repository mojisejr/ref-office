# 02 · เลือกโมเดล

| งาน | โมเดล | เหตุผล |
|---|---|---|
| สร้างหรือแก้ระบบ (โค้ด เครื่องมือ ตัวตรวจ) | **Opus** (`/model opus`) | งานออกแบบ ผิดแล้วกระทบทุกงานหลังจากนั้น |
| รับงานลูกค้าตามปกติ | **Sonnet** (`/model sonnet`) | งานแยกส่วนรายการอ้างอิงไม่ต้องใช้โมเดลใหญ่ และประหยัดโควตาที่ใช้ร่วมกับงานโค้ด |
| งานลูกค้าที่ยาก | สลับเป็น **Opus** ชั่วคราว | ดูเงื่อนไขด้านล่าง |

## เมื่อไหร่สลับจาก Sonnet ไป Opus

- รายการเด้งเกิน 1 ใน 4 ของงาน
- ข้อมูลอ้างอิงมาในรูปแบบแปลก เช่น เขียนปนกันเป็นย่อหน้าเดียว หรือเป็นรูปสแกน
- รายการภาษาไทยที่ตีความไม่ได้ว่าส่วนไหนคือชื่อผู้แต่ง ชื่อเรื่อง หรือสำนักพิมพ์
- งานด่วนที่เวลาเหลือน้อยและรอบแรกไม่ผ่านตัวตรวจ

พอผ่านจุดยากแล้ว สลับกลับเป็น Sonnet

## วัดค่าใช้จ่าย

เป้าตาม gate G1: token ต่องานคิดเป็นราคา API ต้องไม่เกิน 25 ฿ ซึ่งเท่ากับ 10% ของแพ็กเกจเล็กสุด
วิธีวัดในโหมด subscription ยังไม่ได้ตกลงกัน จะกำหนดใน slice 4 (dogfood) แล้วอัปเดตไฟล์นี้
