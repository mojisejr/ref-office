# 03 · หน้าบริการบน Fastwork

หน้าบริการฉบับจริงอยู่ใน [`shop/`](../shop/listing.md) ข้อความใน Fastwork ต้องตรงกับไฟล์ในนั้นเสมอ

## แก้หน้าบริการ

1. บอก agent ว่าจะแก้อะไร agent แก้ไฟล์ใน `shop/` บน topic branch แล้วเปิด PR
2. ก่อนเปิด PR agent เช็กว่าข้อความใหม่ไม่สัญญาสิ่งที่ระบบยังทำไม่ได้
   (เทียบกับ [รายงาน G1](../docs/g1-dogfood.md) และ [scope-lines](../knowledge/scope-lines.md))
   และไม่มีลิงก์ เบอร์โทร LINE หรืออีเมล
3. คุณ merge PR แล้ววางข้อความจาก `shop/` ลง Fastwork เอง
4. ถ้า Fastwork ตรวจหน้าบริการใหม่ ให้รอจนอนุมัติ แล้วบอก agent ให้บันทึกไว้

ถ้าแก้ใน Fastwork ไปก่อนแล้ว ให้คัดลอกข้อความที่แก้มาวางในแชท agent จะนำเข้า `shop/` ให้

## สิ่งที่แก้ไม่ได้หรือห้ามทำ

- **หมวดหมู่:** หลังได้รับอนุมัติแล้วแก้ไม่ได้
- **ราคาแพ็กเกจ:** ขั้นต่ำ 250 บาท ระยะเวลานับเป็นวัน แพ็กเกจด่วน 3 ชม. จึงตั้งเป็น 1 วัน
  และบอกเวลาจริงในรายละเอียดกับใบเสนอราคา
- **ช่องทางติดต่อ:** ข้อตกลงฟรีแลนซ์ของ Fastwork ห้ามติดต่อหรือส่งงานนอกแชทของแพลตฟอร์ม
  หน้าบริการ ภาพ และข้อความตอบทุกอันจึงห้ามมีช่องทางอื่น
